# Metadades per Pujar Episodis a Archive.org

## Instruccions

Per cada episodi, segueix aquests passos:

1. **Login a archive.org**
2. **Upload** → Emplenar formulari amb les metadades següents
3. **Copiar URL resultant** amb format: `https://archive.org/download/[identifier]/[fitxer].mp3`
4. **Actualitzar** el camp `audio_file` del markdown corresponent
5. **Commit i push** dels canvis
